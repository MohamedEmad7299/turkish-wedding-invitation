## ✨ Features

- 🏰 **Ottoman-Inspired Design** — Rich gold, teal & rose color palettes with Ottoman tulip motifs
- 🇹🇷 **Turkish Cultural Elements** — Kına gecesi, halay, nazar boncuğu, Turkish poetry
- ⏳ **Live Countdown Timer** — Real-time countdown to the wedding day
- 💌 **Interactive Guestbook** — Visitors can leave wishes (stored in localStorage)
- 🎵 **Background Music Toggle** — Ambient music player with sound wave animation
- ✨ **Floating Particles** — Gold hearts & stars floating animation
- 📍 **Google Maps Integration** — Embedded venue maps with directions
- 📱 **Mobile-First Design** — Looks perfect on all devices
- 🏙️ **Istanbul Skyline** — SVG mosque silhouettes as decorative elements
- 🎭 **Scroll Reveal Animations** — Smooth entrance animations as you scroll
- 🔄 **Loading Screen** — Elegant loading animation

## 🚀 How to Use

1. Clone the repository
2. Open `index.html` in your browser
3. Navigate between groom and bride pages

### Adding Music
Place your audio files and uncomment the `<source>` tags in `damat.html` and `gelin.html`:
```html
<source src="music/dugun-muzigi.mp3" type="audio/mpeg">
```

### Adding Photos
Replace the emoji placeholders in the gallery sections with actual images:
```html
<img src="photos/your-photo.jpg" alt="Description">
```

## 🛠️ Customization

- **Names & Dates**: Edit directly in the HTML files
- **Colors**: Modify CSS custom properties in `style.css`
- **Venues**: Update Google Maps embed URLs
- **Content**: All text is in Turkish, easily editable

## 📦 Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Grid, Flexbox, Animations
- **Vanilla JavaScript** — No frameworks, no dependencies
- **Google Fonts** — Playfair Display, Cormorant Garamond, Montserrat
